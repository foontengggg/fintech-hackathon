# MacroSignal: Schroders Intelligence Platform

## ABOUT
* **Project Title:** MacroSignal Macro Economics Tracker
* **Team Name:** Money Mari Mari
* **Project Description:** Let's be real, portfolio managers are drowning in information. Every day brings thousands of breaking macro headlines and figuring out what actually moves the market takes hours of manual correlation. We built MacroSignal to cut through the chaos. It is an advanced intelligence platform that acts like a tireless quantitative analyst. Instead of just giving you a wall of news, it compares live headlines against prediction market data. If a story is blowing up in the media but the prediction markets haven't budged, our dashboard visually dims it as "Noise." But when a real "Signal" hits, the platform lights up. Our integrated AI risk strategist instantly reads the shock and maps out the exact downstream consequences. Paired with a multi-asset connector graph and a historical memory vault, MacroSignal is designed to give Schroders asset managers their time back while surfacing the insights that actually matter.

## TECHNOLOGIES USED
* **UI/UX Design:** Figma
* **Frontend Development:** HTML, CSS, JavaScript
* **Backend Data Pipeline:** Python, FastAPI
* **Artificial Intelligence:** OpenAI API for automated risk implication generation
* **Version Control & Hosting:** GitHub

## HOW TO RUN LOCALLY
1. Clone this repository.
2. Install the required Python libraries (e.g., `pip install fastapi uvicorn openai`).
3. Run the backend server using: `uvicorn main:app --reload`
4. Open `index.html` in any modern web browser to view the dashboard.
